# 静界 · 白噪声助手

一款微信小程序白噪声助眠 / 专注工具。**不使用任何音频文件**，11 种环境声全部由 Web Audio API 实时合成，安装包不到 100KB。内置番茄时钟、呼吸训练与正念冥想，UI 采用毛玻璃卡片 + 悬浮胶囊控制条风格，支持深浅双主题。

课程项目：《移动前端设计》团队作业

##  功能

| 功能 | 说明 |
| --- | --- |
| 11 种环境声 | 自然：细雨、暴雨、海浪、微风、溪流、篝火、鸟鸣、虫鸣；ASMR：指弹、键盘、翻书 |
| 声音混合 | 多声音同时播放，每个声音独立音量滑杆 |
| 沉浸式动态界面 | 背景色随所播声音渐变切换；雨点、闪电、火星、萤火虫、波浪等 Canvas 粒子特效实时绘制（零图片资源） |
| 睡眠定时 | 15/30/45/60/90 分钟，最后 30 秒平滑淡出 |
| 番茄时钟 | 经典 25/5、长专注 45/15、轻快 15/3 三种方案，阶段切换钟声 + 振动，今日专注统计 |
| 呼吸训练 | 4-7-8 助眠呼吸与箱式呼吸，动画圆圈引导，每轮钟声提示 |
| 正念冥想 | 3~20 分钟时长预设，颂钵钟声开场收尾，引导语轮换 |
| 推荐场景 | 8 个官方推荐组合（含深夜码字、ASMR 时刻），一键切换 |
| 自定义场景 | 保存当前混音组合，最多 20 个 |
| 深浅双主题 | 播放页右上角一键切换深夜 / 清晨主题，全站即时生效 |
| 现场恢复 | 自动记住上次的播放组合 |

##  声音合成说明

全部声音由代码实时生成，原理：

1. **噪声源**：白噪声（全频段随机）、粉噪声（Paul Kellet 滤波近似）、布朗噪声（积分白噪声）
2. **滤波整形**：BiquadFilter 高通/低通/带通，把噪声"雕刻"成雨、风、浪的频谱特征
3. **LFO 调制**：低频振荡器缓慢调制音量和滤波器截止频率，让海浪有"一阵阵"的起伏
4. **事件音**：定时器随机触发鸟鸣（正弦扫频）、虫鸣（脉冲串）、柴火爆裂（增益尖峰）
5. **ASMR**：指弹（低频闷响）、键盘（高频噪声点击）、翻书（带通扫频沙沙声）
6. **钟声**：三泛音叠加（880/1318.5/1760Hz）长衰减合成颂钵音色，供番茄钟与冥想调用

详见 `utils/audio-engine.js` 内的中文注释。

##  如何运行

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 打开开发者工具 → 导入项目 → 选择本目录
3. AppID 选择「测试号」（或填入自己注册的 AppID）
4. 确认调试基础库 **≥ 2.19.0**（详情 → 本地设置 → 调试基础库）
5. 点击编译，即可在模拟器中运行；也可用手机微信扫码真机调试

> 真机提示：微信要求音频在用户点击后才能启动，首次点击声音卡片即可正常播放。
